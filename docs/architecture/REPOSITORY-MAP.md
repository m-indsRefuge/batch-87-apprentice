# Repository Map

## `governance/`

Externally controlled constitutions, policies, legal registries, authority
rules, and deterministic governance definitions.

## `identity/`

The provisional factual identity and the reserved future self-authored
identity layer.

## `src/batch87_apprentice/memory/`

Application code for:

- Construct and relational memory;
- self and episodic memory;
- session and task memory.

## `memory/`

Database schemas, migrations, and durable memory contracts.

## `development/`

Curriculum design, reviewed developmental journals, and maturity assessments.

## `training/`

Future adapter configurations, corpus manifests, evaluation definitions, and
training-run records.

Large or private training artifacts are excluded from Git.

## `data/`

Runtime databases, evidence, memory records, sessions, and datasets.

Private and generated contents are excluded from Git.

## `experiments/`

Controlled Batch-87 research experiments, beginning with the first
compounding-memory loop.

## `workspace/`

Future bounded working space for Apprentice tasks.

It is scaffolded but grants no current tool authority.

## `docs/devjournal/`

Human-maintained project chronology and accepted development records.

## `docs/legal-regulatory/`

Versioned research and architecture for jurisdiction-aware legal and
regulatory handling.

This directory does not make the Apprentice an independent legal authority.
