# Batch-87 Apprentice

Batch-87 Apprentice is the governed developmental environment for the first
locally hosted Apprentice agent in the Byte–Nolan Construct.

## Current phase

**B87-S1 — Governed Memory Apprentice**

The first objective is to prove that an approved experience from an earlier
task can improve a later decision without repeating the correction manually,
while the process remains observable, permission-bounded, and under human
authority.

## Current programme state

The accepted implementation state extends through B87-I4-A governed retrieval
and context assembly. B87-V0 external persistence validation is accepted and
closed against the I4-A merge baseline.

No implementation slice is currently active. The repository does not connect or
select a real model, configure or start a model server, or authorize an external
model API. B87-I4-B, the provider-neutral model and invocation bridge, is
accepted as a documentation contract but remains unreleased. A scoped V0
regression decision remains an unsatisfied implementation gate and must be
separately reviewed and accepted, and Nolan's exact future release token remains
required before implementation.

## Accepted foundations

- immutable external governance;
- provisional Apprentice identity;
- Construct and relational memory;
- self and episodic memory;
- session and task memory;
- provenance and approval states;
- deterministic permission enforcement;
- governed retrieval and context assembly.

## Reserved future systems

- provider-neutral model and invocation bridge;
- structured model evaluation;
- controlled compounding-learning experiments;
- self-authored identity development;
- agent developmental journals;
- curated training corpora;
- custom adapter training;
- fine-tuning experiments;
- algorithmic memory and retrieval research;
- expanded local tools;
- multi-agent Batch-87 orchestration.

Reserved systems are scaffolded but are not automatically active.

## Authority

Nolan retains final human authority.

Byte provides architecture, synthesis, governance review, and developmental
evaluation.

The Apprentice begins as a supervised observer and analyst. It may not grant
itself authority, approve its own permanent memories, or perform consequential
actions without explicit external permission.

## Data boundary

Private memories, live databases, raw evidence, session records, datasets,
model files, credentials, logs, and training outputs are excluded from Git by
default.

Only reviewed schemas, manifests, policies, source code, tests, and approved
documentation should be committed.
